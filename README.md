# I3 Typing Master v2026

## Project Description

I3 Typing Master v2026 is a simple Java console application designed to simulate a typing test system.  
It allows users to interact with basic features such as registration, login, password reset, and typing practice.

---

## Features

- User Registering
- User Reset Password
- User Login
- View Test Results
- Typing Test
- About Us Section

---

## Technologies Used

- Java (JDK)
- Console (Command Line Interface)
- Scanner Class
